# speedtest.js

Консольный скрипт на Node.js для замера скорости скачивания по URL.

## Что делает

1. Принимает URL (например, тяжёлую картинку или любой файл).
2. Делает **10 последовательных** GET-запросов, дожидаясь полного ответа на каждый.
3. Считает:
   - среднее время одного запроса,
   - общий объём скачанных данных,
   - **скорость скачивания**.
4. Печатает результат в консоль.
5. Скорость считайется в байтах/сек

## Требования

- Node.js 14+ (используются только стандартные модули `http`, `https`, `url`).
- Внешних зависимостей нет.

## Запуск

```bash
node speedtest.js <URL> [--requests=N]
```

### Примеры

```bash
# 10 запросов по умолчанию
node speedtest.js https://example.com/big-image.jpg

# 20 запросов
node speedtest.js https://example.com/big-image.jpg --requests=20
```
